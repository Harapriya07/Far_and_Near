Far & Near

Far & Near is a playful digital space designed for long-distance friends to stay connected, share experiences, create memories, and make distance feel a little smaller.

Whether it's playing games together, completing bucket lists, or simply spending quality time, Far & Near brings people closer, no matter how far apart they are.

Features>

- **Private Shared Space:** Connect with your partner through a unique invite code.
- **Interactive Games:** Enjoy fun multiplayer games together.
- **Ludo:** Challenge each other in a classic board game.
- **Shared Bucket List:** Create, track, and complete experiences together.
- **Personal Connection:** A dedicated space for two people to share moments and memories.
- **Responsive Design:** Enjoy the experience across desktop and mobile devices.

Tech Stack>

- React 19
- Vite 7
- JavaScript (JSX)
- React Router
- CSS3
- React Context API
- Local Storage

Getting Started

Prerequisites
- Node.js
- npm

Installation
```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.
